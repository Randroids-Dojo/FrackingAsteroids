Start Screen

Status: done

The Start Screen is the entry point of the game, shown when the app launches. It lets the player begin a new game or load an existing one, using three save slots.

Full-screen menu, title, and tagline

  • Full-screen menu shown on app launch.
  • Title "FRACKING ASTEROIDS" with a tagline.

New Game

  • New Game button opens a save slot picker (3 slots).

Load Game

  • Load Game button opens a save slot picker (3 slots).

Save slot timestamps

  • Each save slot shows its last-save timestamp.

localStorage summaries

  • Save slot summaries are stored in localStorage for instant display.
