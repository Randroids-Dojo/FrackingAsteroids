HUD

Status: done

The HUD is always visible during gameplay. It surfaces resource state, ship status, weapon readiness, and aim guidance without taking input focus away from the play field. The elements below are ported from the GDD User Interface section.

HUD elements

ElementPlacementShows
Scrap counterTop-leftCurrent scrap amount
Cargo barTop-left, below scrapFragments / capacity
Upgrade indicatorsTop-rightCurrent tier for each system
Recharge meterSmall horizontal bar below shipBlaster cooldown progress
Health barTop-left (shown when HP below max)Hull HP remaining
Pause buttonTop-right corner (mobile: larger touch target)Pause / resume control

Aim reticle

The aim reticle is a red, dashed, semi-transparent line projected from the center of the ship in the aim direction (mouse on desktop, right firing joystick on mobile). The line extends to the edge of the visible screen, or stops early when it intersects an asteroid or enemy ship.

A red target circle (reticle) marks where shots will land: centered on the screen-edge endpoint when nothing is in the way, or snapped onto and sized to the intersected object (asteroid or enemy).

The aim reticle is hidden during the scripted prologue.

Related HUD colors

The HUD color palette uses #00FF88 (green), #00AAFF (blue), #FF4444 (red), and #FFAA00 (amber).
