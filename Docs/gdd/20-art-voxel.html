Art Style: Voxel

Status: done

The game uses a voxel-style 3D art direction. All visible game objects are built from cube (box) voxel geometry assembled into THREE.Group meshes. This section captures the voxel construction rules for each object class.

Voxel construction rules

All game objects
Built from voxel-style geometry (box voxels).
Ship
A roughly 8x8x4 voxel block ship with engine glow.
Asteroids
Irregular voxel clusters, procedurally varied per type.
Fragments
Small 1 to 2 voxel glowing cubes.
Projectiles
Bright amber elongated voxel pulses (mining laser bolts).
Background
Particle-based star field.

All game objects are voxel geometry

Every game object class (ship, asteroids, fragments, projectiles) is constructed from cube voxels assembled into THREE.Group meshes. The background is the one layer that uses particle points rather than voxel cubes.
