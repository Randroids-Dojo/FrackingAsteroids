Pause Overlay

Status: partial

The pause overlay is the UI shown when the game is paused. On desktop, pressing Space pauses the game and reveals the Feedback FAB. A Pause button also lives in the HUD (top-right corner; larger touch target on mobile). The overlay surfaces the paused state without obscuring the game world entirely.

The pause overlay consists of the following elements:

  • Darkened game canvas: the game canvas is dimmed behind the overlay.
  • "PAUSED" text centered: the word PAUSED is displayed centered over the dimmed canvas.
  • Resume control: resuming is driven by the HUD pause button toggling to a play icon (see HUD pause control below), not a dedicated button inside the overlay.
  • Feedback FAB: a floating action button that appears in the bottom-right corner while paused.

Related controls and context from the surrounding spec:

Desktop pause
Space pauses the game and reveals the Feedback FAB.
HUD pause control
Pause button in the top-right corner of the HUD (mobile: larger touch target).
Feedback submission
The Feedback FAB submits player feedback through the POST /api/feedback route.
