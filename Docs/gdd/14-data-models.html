Data Models (Zod Schemas)

Status: done

The persisted game state is described by a small set of Zod schemas. These schemas are the contract for save/load: the same shapes flow through the React UI state, the Three.js render loop, and the Upstash Redis persistence layer. The canonical shapes are:

Ship { x, y, rotation, velocityX, velocityY }
Upgrades { blaster: number, collector: number, storage: number }
Cargo { scrap: number, fragments: number, silver: number, gold: number, capacity: number }
GameState { ship, upgrades, cargo, hp, timestamp }

Ship

The ship schema captures the ship's position, facing, and motion in world space.

FieldTypeMeaning
xnumberWorld-space x position
ynumberWorld-space y position
rotationnumberFacing angle (radians)
velocityXnumberVelocity along x
velocityYnumberVelocity along y

Upgrades

The upgrades schema tracks the current tier (1 to 5) for each of the three ship systems.

FieldTypeMeaning
blasternumberBlaster tier
collectornumberCollector tier
storagenumberStorage tier

Cargo

The cargo schema holds the player's resources and the cargo hold capacity.

FieldTypeMeaning
scrapnumberCurrency (converted from fragments)
fragmentsnumberUncollected or unconverted fragments
silvernumberSilver material count
goldnumberGold material count
capacitynumberCargo hold capacity (storage tier 1 default is 50)

GameState

The top-level game state composes the ship, upgrades, and cargo schemas, plus the player's HP and a save timestamp.

FieldTypeMeaning
shipShipShip position, facing, and motion
upgradesUpgradesCurrent tier per system
cargoCargoResources and capacity
hpnumberPlayer HP (0 to 100; 100 default)
timestampnumberLast-save time (epoch ms)

State management context

  • Game state lives in the Three.js render loop (60fps).
  • React state for UI/HUD via the useGameState hook.
  • Persistence via the useGamePersistence hook backed by Upstash Redis.
  • Auto-save fires on resource collection, selling, buying, and station repair.
  • A headless GameSimulation mirrors scene orchestration for integration testing.
