Consume vibekit headless joystick

Branch
feat/joystick-vibekit-headless
PR
TBD
Changed
Refactored src/game/virtual-joystick.ts so both the movement joystick and the firing joystick delegate headless state to vibekit's createJoystick / beginJoystick / moveJoystick / endJoystick / readJoystick instead of hand-rolled origin tracking. FrackingAsteroids keeps ownership of the DOM overlay, the left-half / right-half touch regions, the 10px dead zone, the 0.3 cardinal threshold, and the existing InputState / fire-angle outputs. vibekit's joystick normalizes deflection over its JOYSTICK_RADIUS (64), which only affects deflection magnitude; FA reads sign-thresholded cardinals plus the direction angle, so activation direction and rotation are unchanged.
Verification
npm run type-check, npm run lint, npm run format:check, npm run test:unit (558/558, including tests/unit/virtual-joystick.test.ts 34/34), npm run test:integration (28/28), and git diff --check passed. Dash scan returned no matches.
Assumptions
FA only consumes cardinal direction and angle from the joystick, so adopting vibekit's 64px deflection radius in place of the prior 50px is a no-op for gameplay direction.
GDD coverage
unchanged. Build log appended to Docs/gdd/09-controls.html.
Followups
